📬 Notifikasi Telegram
Opsional

Aktifkan notifikasi otomatis ke Telegram setiap kali operator menginput Data Paket atau Rincian Belanja. Notifikasi dikirim langsung ke akun / grup Telegram admin.

Notifikasi Telegram Nonaktif
Aktifkan untuk mulai menerima notifikasi di Telegram
Dapatkan dari @BotFather di Telegram. Buat bot baru → salin token yang diberikan.
Gunakan @userinfobot untuk ID pribadi, atau @RawDataBot untuk ID grup (diawali tanda minus -).
📖 Cara setup Bot Telegram (klik untuk buka)
  1. Buka Telegram, cari @BotFather → kirim /newbot
  2. Ikuti instruksi: masukkan nama & username bot → salin Bot Token yang diberikan
  3. Untuk Chat ID pribadi: cari @userinfobot → kirim /start → salin angka ID-nya
  4. Untuk Chat ID grup: tambahkan bot ke grup, lalu cari @RawDataBot di grup → salin ID (dimulai -)
  5. Pastikan bot sudah ditambahkan ke grup jika menggunakan Chat ID grup
  6. Isi token & chat ID di atas → klik Kirim Pesan Test → jika berhasil, aktifkan toggle & simpan
💬 Notifikasi WhatsApp
Opsional

Kirim notifikasi otomatis ke WhatsApp setiap kali operator menginput Data Paket, Rincian Belanja, atau Survey Harga. Menggunakan layanan CallMeBot (gratis, tanpa backend).

Notifikasi WhatsApp Nonaktif
Aktifkan setelah mengisi nomor & API key di bawah
📱 Cara Daftar CallMeBot (sekali saja, GRATIS):
1. Simpan nomor +34 644 59 39 99 di kontak HP Anda
2. Kirim pesan WA: I allow callmebot to send me messages
3. Tunggu balasan berisi API Key (1–2 menit)
4. Masukkan nomor & API key di bawah, lalu klik Simpan & Test
Format internasional tanpa tanda + (cth: 628123456789)
